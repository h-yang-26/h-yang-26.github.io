    Synthetic Data Quality Pipeline

    Related professional work: Inventory data migration and exception review

    Problem
    Inventory records mix missing identifiers, ambiguous categories and quantities that look alike but mean different things.
    Method
    A seeded command-line pipeline normalizes and validates fictional records, maps categories by exact alias, and routes ambiguous or invalid rows to a traceable exceptions file instead of guessing.
    Recorded result
    60 input rows = 37 accepted + 23 rejected; 21 tests passed (agent-run).

  • Independent / Synthetic Demonstration

    Inventory and Shipping Optimization Lab

    Related professional work: Implemented inventory recommendation capability

    Problem
    Shipping every requested unit is not always worthwhile when opening a container incurs a fixed charge.
    Method
    An integer program solved with PuLP and CBC allocates fictional stock under demand, mass and volume limits, trading shortage penalties against container charges. A separate checker revalidates every plan.
    Recorded result
    Five scenarios reproduce byte-identical results; 130 tests passed (agent-run).
    • Python
    • PuLP/CBC
    • Integer optimization
    • Independent feasibility checks

  • Hypothetical Systems-Design Exercise

    B2B Sales Systems Case Study

    Related professional work: Deployed industrial B2B platform development

    Problem
    A quotation, an accepted order, reserved stock and a shipment are different business facts; adding them together double counts demand.
    Method
    A documented sales lifecycle, entity glossary, Mermaid diagrams, three architecture decision records and five metric definitions, checked by a small standard-library calculator. The architecture is a proposed design, not an implemented system.
    Recorded result
    Consistency checks PASS; 30 unittest tests passed (agent-run).
    • Domain modeling
    • Mermaid
    • Architecture decision records
    • Python standard-library checks
